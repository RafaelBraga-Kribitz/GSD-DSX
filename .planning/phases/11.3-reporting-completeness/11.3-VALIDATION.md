## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Python stdlib `unittest` (no pytest / no third-party test framework in the repo) |
| **Config file** | none — `python -m unittest discover -s tests -q` (see `scripts/check.sh`) |
| **Quick run command** | `python -m unittest tests.<module> -v` (the specific new/edited module) |
| **Full suite command** | `python -m unittest discover -s tests -q` (1147 tests as of 2026-08-26) |
| **Phase gate** | `bash scripts/check.sh` (full suite + `gen-finding-catalogue.py --check` + capability manifest + gate-contract good/bad/missing exit codes + determinism) |
| **Estimated runtime** | ~60–90 seconds (full suite) |

---

## Sampling Rate

- **After every task commit:** Run `python -m unittest tests.<edited module> -v`, plus `python scripts/gen-finding-catalogue.py --check` whenever a `report.add(...)` call site changes.
- **After every plan wave:** Run `python -m unittest discover -s tests -q` (full suite).
- **Before `/gsd-verify-work`:** `bash scripts/check.sh` must be green.
- **Max feedback latency:** ~90 seconds.
