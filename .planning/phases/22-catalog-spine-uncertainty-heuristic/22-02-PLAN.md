<objective>
Mint the single new gate code this phase introduces — DSX-VIZ-071, the uncertainty-
vocabulary check that refuses a declared uncertainty mark outside Wilke's ten §5.6 members
— carry its D-05 citation the enforced way (allowlist + docstring + test marker), and prove
the finding-code catalogue grew additively from 275 to 276 by bumping the load-bearing
set-identity invariant.

This is a code-and-test change to the gate. It implements REQ-P22-05 (gates extended for
the new vocabulary; every new code carries a D-05 citation; the additive-only mint proven
against the re-measured 275 baseline). DSX-VIZ-071 answers the *selection* concern ("which
mark communicates the uncertainty?") and is complementary to the retained property-based
DSX-VIZ-070 ("did you show uncertainty at all?") — neither subsumes the other.

Purpose: without this plan the "uncertainty" relationship from Plan 22-01 has a
recommendation surface but no membership gate, and the phase mints no code. This plan is
also where the milestone's additive-only discipline is proven for Phase 22: the mint is
real only if tests/test_finding_catalogue_invariant.py is bumped in the same wave
(Pitfall 2), and D-05 is enforced only if DSX-VIZ-071 is allowlisted by exact string
(Research Pattern 3).

Output: one new gate function minting DSX-VIZ-071, one exact-string allowlist entry, a
regenerated catalogue at 276, a bumped set-identity invariant, and a new gate-behaviour
test carrying the D-05 marker.

## Decision recorded loudly (HQ-30 veto window; silence = accept): DSX-VIZ-072 is NOT minted

GA-3 reserved DSX-VIZ-072 contingently, "only if plan (S2-2) finds a second distinct
uncertainty check is warranted (e.g. paradigm-mismatch detection)." The plan finds it is
NOT warranted, for a concrete reason: the ten §5.6 marks are deliberately paradigm-
symmetric — that symmetry IS the D-12a-clean property (GA-2). Several marks (error bars,
graded error bars) legitimately render either a frequentist confidence interval or a
Bayesian credible interval, so there is no clean mark→paradigm partition to check against.
A paradigm-mismatch gate would manufacture a false constraint and contradict the very
symmetry the family exists to express. REQ-P22-02's "D-12a-clean" is satisfied by
construction (the 11th-key structure), needing no enforcement code. Therefore Phase 22's
blocking-code footprint is exactly one: DSX-VIZ-071. The set-identity diff proves 275 → 276.
This is a persona-round numeric-assignment decision (brief §4: silence = accept); it is
recorded, not escalated.
