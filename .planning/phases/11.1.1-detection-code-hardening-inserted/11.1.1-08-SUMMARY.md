1. **WR-02 Option B is now CLOSED IN CODE.** A declared-but-unscannable entrypoint — both the `path is None` and `source is None` early returns — produces exactly one `scan_path:not-scanned:<reason>` decision record, so `DECISIONS.jsonl` gets an entry and `dsx explain` can replay the judgment.
