### Concrete SC4 proof procedure

Run `python -m unittest tests.test_known_bad_corpus -v` before and after the code
change and diff the two runs.
`test_every_spec_blocks_only_on_its_target_defect_at_critical_threshold_points`
(`tests/test_known_bad_corpus.py:611`) already asserts every fixture's `plan` and
`execute` exit code against its recorded target-defect map on every run, so an
unintended exit-code move fails that existing test automatically. No new
assertion is needed — only a clean before/after run.
