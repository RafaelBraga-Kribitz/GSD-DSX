<objective>
Widen the causal-verb lexicon so bare-infinitive and gerund action forms are caught, structured as two
tiers, so the flagship "offer bundled incentives to reduce churn" no longer evades detection — without
false-positiving on nouns like "sales increase in Q4".

Purpose: CAUSAL_VERBS (spec.py:54-60) today has finite verbs (`increases`, `reduces`, `drives`, …) but
lacks bare infinitives (`reduce`, `increase`, `decrease`) and gerunds (`reducing`, `increasing`), so a
recommendation phrased "...to reduce churn" passes clean. D-04 fixes this with a false-positive-
conservative context gate, NOT an epistemic softener: bare/noun-homograph forms fire only inside a
purpose/recommendation construction; gerunds fire as ordinary verb hits and route through the existing
HEDGE_TERMS softener like every other verb.

Output: a tiered CAUSAL_VERBS with a shared `causal_verb_matches` helper and a bounded purpose-context
regex, both consumers routed through it, an umbrella provenance header, and scoped tier tests.
</objective>
