<objective>
Show the operator what the gate took on trust. dsx explain gains a separately-labelled self-reported
section after the decision trail — every value the gate compared but never computed (all
validity_frame.*, inference.*, analysis.test, declared_at) — so a reader cannot mistake a
self-reported value for a computed verdict.

Purpose: the decision trail today shows computed choices; it does not disclose the trust boundary —
which inputs the gate accepted as declared. A separate labelled section is the clearest disclosure and
removes the risk of a reader reading a declared value as a verdict. frame_digest is computed, so it
stays in the computed header line and must never be labelled self-reported — the inverse would be the
exact honesty inversion this project exists to prevent.

Output: the labelled section in _render_decision_trail fed from cmd_explain's spec load, with escalate
and the returns-0 contract untouched.
</objective>
