<objective>
Make a declared algorithm owe an account of how it was chosen, and make the two ways of choosing it
that invalidate the reported score into findings.

Purpose: the reproduction searches an eighteen-candidate roster by grid or random search, evaluates
by cross-validation, and combines the best into an ensemble. Nothing in the contract records that a
search happened, so nothing can ask whether the data that chose the model is the same data that
scored it. A selection made on the test set is not a model evaluation; it is a description of the
test set.

Output: an optional selection ledger on the model block, three new finding codes, template scaffold,
tests, a decision record and a current catalogue.
</objective>

| specification author to gate | The ledger's three fields are analyst-supplied and untrusted. A ledger declared as the wrong type must degrade, not raise. |

| template scaffold to every future specification | An uncommented ledger in the template would make it a de facto requirement of every new specification. |
