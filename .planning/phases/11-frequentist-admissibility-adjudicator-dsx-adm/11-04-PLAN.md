<objective>
Create `references/families.yaml` — the estimator ontology the adjudicator reads — as data, with a
citation on every family, and the test file that pins its schema.

Purpose: this is the phase's first headline artifact and everything downstream keys on it. The
ontology must exist, and its citations must exist, before any code is written against it. The file
is parsed by the already-shipped `dsx.loader.load()`, which is two parsers that measurably disagree,
so the schema deliberately avoids every construct on which they diverge.

plus `tests/test_families_yaml.py` proving the schema mechanically.
