<objective>
Rank the admissible set, name what each entry buys and charges, and ship the two `DSX-ADM-*` codes
with the guard set their existence trips.

Purpose: REQ-P11-03 asks for a ranked admissible set naming assumptions bought and charged.
REQ-P11-04 asks that an underdetermined frame refuses rather than guesses. Ranking is a rule table
because admissibility is a partial order by construction — uniformly most powerful tests do not
exist for two-sided or general composite alternatives — and a scoring function would assert a total
order that no source supports. The refusal is one code with three causes, because all three share
one remedy and finding numbers are irreversible.

Output: `rank_admissible()`, `admissible_families()` and `check()` in `dsx/frame/admissibility.py`,
`DSX-ADM-010` at HIGH and `DSX-ADM-020` at CRITICAL, the catalogue prefix group, the
`_NOT_SHIPPED` deletion, and a regenerated `references/finding-codes.md`.
</objective>
