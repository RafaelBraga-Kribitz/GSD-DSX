## How to resume

Do **not** start with a plain `/gsd-execute-phase 8`. That would re-run Wave 1 from scratch.

1. Confirm Phase 09 has finished and its worktrees are cleaned up (`git worktree list`).
2. Merge the two tagged branches into the settled branch, one at a time:
   `git merge gsd-safety/08-01-wave1` then `git merge gsd-safety/08-02-wave1`.
3. Resolve `tests/test_known_bad_corpus.py` by hand. Read both versions side by side and keep
   both maps — Phase 09's expected-caught-defect map and Phase 08's target-defect map serve
   different purposes. Do not accept a clean auto-merge without reading the result.
4. Also re-check `dsx/mathx.py` and `tests/test_dsx.py` for silent auto-merges.
5. Run the full test suite. Both phases' tests must pass together before continuing.
6. Confirm `08-01-SUMMARY.md` and `08-02-SUMMARY.md` are present in the phase directory, then
   run `/gsd-execute-phase 8` — the plan index will now see Wave 1 as complete and start at Wave 2.
7. Delete the two safety tags once the merge is verified green.
