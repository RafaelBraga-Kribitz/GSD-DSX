<corrections_applied>
**The reworded success criterion this plan delivers against.** ROADMAP success criterion 3 says a
test asserts the dilution identity "against the Deng & Hu (2015) **published value**". Primary-text
research read all ten pages of the paper: it contains no additive worked example at all. Every
number in it is for a ratio metric. Decision D-10 rewords the criterion to "published
**counterexample**" — the time-to-success case, a true effect of −26 msec against the naive
formula's −18 msec. That metric is a ratio, so the same test simultaneously proves the additive-only
scope boundary REQ-P8-04 demands. This is a factual correction, not a lowered bar. Plan 08-01
already landed the test; plan 08-06 amends the ROADMAP text.

**REQ-P8-04's entry condition is rewritten because its premise is false.** REQ-P8-04 and ROADMAP
success criterion 4 defer ratio-metric dilution on the condition that the Deng & Hu ratio equation
"is obtained from primary source". The paper is freely public at
`https://alexdeng.github.io/public/files/wsdm2015-dilution.pdf` and its ratio equation — Formula (3)
in section 3.3 — is readable now, so that condition is already met and would unblock immediately.
The real blocker is mathematical: Formula (3) sums over individual users and has no closed-form
scalar multiplier, so it needs per-user data a declaration-only gate never has. Task 2 writes
*that* as the entry condition. It may be permanently out of scope rather than deferred, and the row
must not promise otherwise.

**The section 6.5 row is new, not an edit.** `08-RESEARCH.md` read `brief.md` lines 364 to 390
directly and confirmed the gated-backlog table currently carries no row about ratio-metric dilution
or the Deng & Hu ratio equation. The documentation-content test therefore tests for presence, which
is simpler than testing for a changed wording.
</corrections_applied>
