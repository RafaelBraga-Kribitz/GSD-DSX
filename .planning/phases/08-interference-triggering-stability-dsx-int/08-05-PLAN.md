<objective>
Ship `DSX-INT-040`, the novelty and primacy check, at HIGH so it flags at verify and ship without
blocking planning — then harden the whole module against a malformed sub-block of any of the three
shapes it reads.

existing shipped check has to be stated in the finding itself. `DSX-EXP-030` already adjudicates
the declared duration and its own detail text already uses the word "novelty"; this code
adjudicates whether the assessment happened, not how long the window was.

Output: the fourth interference code, its disjointness statement, and the security hardening pass
that closes the phase's two denial-of-service threats across all four codes at once.
</objective>
