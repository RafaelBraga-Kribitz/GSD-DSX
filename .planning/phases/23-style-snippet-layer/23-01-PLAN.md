<objective>
Create the top-level `styles/` directory: vendor exactly one OFL font family (Lato
Regular + Bold + its OFL.txt), and author the four license-audited `.mplstyle` files —
`dsx-538` (fork of matplotlib's bundled `fivethirtyeight`, Matplotlib License), `dsx-urban`
(Apache-2.0 palette + vendored Lato, the documented **house default**), and `dsx-econ` /
`dsx-bbc` (reimplemented from published doctrine only, no proprietary font, no GPL port, no
PDF embed). Each file opens with a per-file license/attribution header. All four ship
WCAG-AA contrast-verified palettes with per-palette citations.

This plan implements REQ-P23-01 (the style-file set + per-file headers + the license-audit
plan-review item) and REQ-P23-05 (WCAG-AA palettes ship in the style files; the palette
*gate* is D-13-deferred, no code minted). It is Wave 1: the vendored font and the style
files are the build-order prerequisites Plan 02's determinism test depends on
(font → helper → determinism-test).

Purpose: without a vendored deterministic house face and a set of styled, accessible
palettes, there is nothing for `dsx_plotstyle.py` (Plan 02) to render under and nothing for
the snippet catalog (Plan 03) to demonstrate. This plan is also where the milestone's
license discipline is discharged for the three vendored assets.

Output: `styles/*.mplstyle` (4), `styles/fonts/Lato-*.ttf` + `OFL.txt`, and two
repo-integrity tests (header presence, WCAG-AA contrast). Zero finding codes minted.
