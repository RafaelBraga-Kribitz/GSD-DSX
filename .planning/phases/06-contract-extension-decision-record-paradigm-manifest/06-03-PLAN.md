<objective>
Make D-05 mechanical rather than review-only: extend `scripts/gen-finding-catalogue.py` so
`--check` fails the build when a new-in-v2.0.0 finding code lacks a primary-source citation, lacks
a reference value or named structural criterion, or has no linked test (REQ-P6-11, M-08,
D-20 through D-23).

Purpose: ROADMAP ordering constraint 3 puts this before any frame check carries logic. If the
enforcement lands after `DSX-SPEC-08x` and `DSX-PAR-001`, there is a window in which an uncited
check ships undetected. Landing it first means every new code in this milestone is born compliant
and the constraint is enforced by construction rather than by discipline.

Output: `check_d05()` wired into `--check`, a `DSX-PAR` prefix group so the new family renders, a
deliberately violating fixture, and the meta-tests proving both halves of D-05 can actually fail.
</objective>
