<assumption_delta_decision>
## The analysis paradigm goes from implicitly singular to plural

**The noun that is now primary:** the **declared analysis paradigm** — `inference.paradigm`, a
member of `PARADIGMS`. Before this phase, "frequentist" was never named because it was the only
option; every check that made a paradigm-dependent assumption made it silently. From this phase on,
the paradigm is a declared, plural property of the spec.

**Decision: `promote`.** Check-family applicability becomes a first-class function of the declared
paradigm, with `frequentist` as one variant of the general rule rather than the assumed default
around which `bayesian` is an exception path. Concretely, `dsx/frame/paradigm.py` holds one
applicability map keyed by every member of `PARADIGMS`, and `DSX-PAR-001` computes the applied and
not-applied sets by the same code path for every member. There is no branch of the form "if
bayesian, do the special thing, else the normal thing".

**Rationale:** `DSX-PAR-001`'s job — naming which families applied and which did not — is the
observable consequence of this choice, and it is only truthful under `promote`. Under
`add-alongside`, a frequentist run would print nothing (the assumed default needs no manifest)
while a Bayesian run would print an exception notice, which reintroduces exactly the steering D-12
exists to prevent: one paradigm cheaper to satisfy than the other.

**The third state is explicit, not defaulted.** A spec that declares no `inference.paradigm` is
neither frequentist nor bayesian. The manifest still emits, naming that no paradigm was declared
and that therefore no paradigm-conditional family was selected. Silently treating an undeclared
paradigm as frequentist would be the demoted-old-default anti-pattern wearing a new name.

**Accepted debt:** none from this decision. The residual limitation is that only `DSX-PAR-001`
exists to consume the map in this phase; Phases 7 through 11 add their families to it as they ship,
enforced by the invariant test in Task 2 rather than by memory.

**Invariant test encoding the generalized intent** (a real task, Task 3): for every member of
`PARADIGMS`, an otherwise-clean spec declaring that paradigm exits 0 at all four gate points and
its output names both an applied and a not-applied set.
</assumption_delta_decision>
