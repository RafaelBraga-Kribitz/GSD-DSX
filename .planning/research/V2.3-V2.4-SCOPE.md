# V2.3 / V2.4 Scope — Analytic Excellence (tests, charts, style)

**Date:** 2026-08-29. **Status:** operator-directed scope, handed to the autonomous
ceremony. **Research provenance:** 6-agent research workflow (2 repo mappers, 3
domain researchers, 1 adversarial completeness critic), 2026-08-29; findings
verified against the live tree at `main` post-v2.2.0.

**Operator intent (verbatim gist):** (1) an as-exhaustive-as-manageable chart/plot
catalog, a great question→chart selection heuristic, and a catalog of pre-made,
publication-grade snippet/style directives (The Economist, FiveThirtyEight class);
(2) a near-exhaustive statistical-test catalog with correct implementations and
question→test heuristics. Output must survive scrutiny by highly capable DS
professionals — portfolio-grade. v3.0 (models) is future scope, untouched here.

**Split decision: two sequential milestones, tests first.**

- **v2.3 Test Catalog** — Phases 17–20, branch `gsd/v2.3.0-test-catalog`, tag `v2.3.0`.
- **v2.4 Visual Excellence** — Phases 21–24, queued; tag `v2.4.0`.

Why this split and order (critic's synthesis, adopted):
1. Both subjects append to single-writer files (`references/finding-codes.md`,
   `templates/ANALYSIS-SPEC.yaml`, shared skills) and D-06 makes code-range
   collisions permanent — never interleave the milestones.
2. The test subject starts with **mandatory repairs** (see "Inherited defects"
   below) and carries the heavier D-05 human-read burden (~15–20 reads vs ~8–12);
   front-load it while the operator queue is fresh.
3. The portfolio exemplar capstone consumes BOTH subjects, so it terminates v2.4.
4. Contingency (pre-agreed): if v2.3's D-05 queue materially outruns the ceremony
   cadence, split v2.4 into v2.4 (catalog/gates) + v2.5 (style/snippets/exemplar) —
   the style layer needs almost no human reads and must not be blocked behind
   the uncertainty-vocabulary reads.

**Scope-boundary note (versus v2.0.0's out-of-scope list).** v2.0.0 excluded "a
catalogue of every named statistical test." That exclusion is about the GATE:
`families.yaml` remains the admissibility ontology (families, not tests) and no
gate computes a statistic. What v2.3 expands is the **routing surface** — the
`recommend_test` decision table (which already ships and is already gate-checked)
plus a bounded set of **declaration-only** defect checks. A ~75-row decision table
keyed one-primary-answer-per-declarable-key is not "every named test" (Kanji
enumerates 100, Sheskin ~200; most are redundant answers to the same key or
obsolete). This mirrors the v2.2 precedent of promoting a former out-of-scope item
by explicit note, not silent reversal.

## 1. Inherited defects that gate everything (v2.3 Phase 17 — fix FIRST)

1. **Boschloo doc/code divergence (live bug).** `references/test-selection.md`
   footnote 1 prescribes Boschloo's exact as the small-expected-cell fallback
   (Lydersen, Fagerland & Laake 2009 §9, verified citation), but
   `dsx/checks/stats.py:65` still emits `fisher_exact (any expected cell < 5)` and
   `boschloo_exact` is absent from `NONPARAMETRIC_TESTS` (stats.py:25), so a
   declared boschloo escapes parametric/nonparametric gating. Every new row
   inherits this divergence class until it is fixed and pinned by a regression test.
2. **Spec-vocabulary gap.** Several planned gates key on question granularity the
   spec cannot declare: agreement vs method-comparison vs ordered-trend vs
   linear-vs-monotone association. `QUESTION_TYPES` is a closed 5-key list
   (dsx/spec.py). A new additive closed vocabulary (working name `estimand_kind`)
   must ship before any gate that reads it.
3. **`recommend_test` is a total function with an unconditional `time_to_event`
   fallthrough** (stats.py:128-129). New outcome-type rows must be inserted before
   it, guarded by a fallthrough-position regression test, or routing silently changes.
4. **D-06 range pre-allocation from the LIVE count.** Do not trust "260" — re-run
   the catalogue invariant and pre-allocate ranges per category in the first commit.
5. **Viz matrix internal inconsistency (v2.4 Phase 21 — fix FIRST there).**
   `histogram, density, ecdf, strip, diverging_bar, waterfall, dumbbell, bump,
   sankey, kde` sit in `RELATIONSHIP_CHARTS` (or smells sets) but in **no**
   `CHART_CAPABILITIES` family → guaranteed DSX-VIZ-013 friction;
   `population_pyramid`/`butterfly` are admissible by input type but reachable from
   no relationship. An every-mark-has-a-home invariant test must land before the
   catalog grows on this base.

## 2. v2.3 Test Catalog — content plan

### 2.1 Decision-table expansion (~15 rows today → ~75)

Eleven categories, each row carrying: decision key (declared fields only), test,
effect size, primary citation, controversy/deprecation note. Full row-level detail
with citations sits in the research workflow output (journal preserved); headline
per category:

|---|----------|----------------------|----------|
| 1 | Correlation/association | GATE + catalog | Pearson (+Fisher-z CI, Pearson 1896/Fisher 1921), Spearman (1904), Kendall tau-b (1938), point-biserial (Tate 1954), phi (Cramér 1946); dCor (Székely-Rizzo-Bakirov 2007) catalog-only pending D-05 fixture; partial-correlation pointer |
| 2 | Agreement/reliability | GATE + catalog | Cohen's kappa (1960), weighted kappa (1968, declared weights), Fleiss (1971), Krippendorff alpha (Hayes & Krippendorff 2007 worked value), ICC as declared (model,type,definition) triple (Shrout & Fleiss 1979; McGraw & Wong 1996; Koo & Li 2016), Bland-Altman (1986) for method comparison; Cronbach→omega pointer (Sijtsma 2009; McNeish 2018) |
| 3 | Repeated measures 3+ | GATE + catalog | RM-ANOVA with **unconditional Greenhouse-Geisser** (1959; Maxwell & Delaney 2004 ch. 11-12 — the RM analog of always-Welch), Friedman (1937), Cochran's Q (1950), Page's L (1963); mixed-model (Laird-Ware 1982) and GEE (Liang-Zeger 1986) pointer rows |
| 4 | Trend/dose-response | partial GATE | Cochran-Armitage (1954/1955, declared dose scores), Jonckheere-Terpstra (1954/1952), Page's L, Mann-Kendall + Sen (Mann 1945; Hamed & Rao 1998 autocorrelation declaration) |

| 6 | Resampling | GATE + catalog (most D-02-friendly) | Permutation (Fisher 1935; Pitman 1937), percentile bootstrap (Efron 1979), **BCa house default** (Efron 1987); gate: declared resampling requires seed+B+unit+method quadruple (B conventions: Davidson & MacKinnon 2000) |

~7 rows are deliberate DEPRECATED/negative-routing entries; ~6 are pointer rows
with no gate. Deprecated entries are first-class rows that route people OFF the
method, mirroring the shipped Fisher/Boschloo footnote-1 honesty.

### 2.2 New gate checks (8 ± 1, ALL declaration-only, stdlib-only)

Correlation scale-match; agreement declaration completeness (ICC triple, weighted
weights, kappa companions per Feinstein & Cicchetti 1990); two-stage sphericity
ban; Mann-Kendall autocorrelation declaration; post-hoc/omnibus family match;
resampling seed/B/unit/method quadruple; variance-test-as-precondition ban;
observed-power ban; exposure-offset presence. Every one compares declared strings/
structures in ANALYSIS-SPEC.yaml — no computation, no data.

### 2.3 Doctrine dispositions (settle at Phase 17, not per-check)

- **D-12a:** most checks are paradigm-neutral (declaration completeness/
  consistency). The observed-power ban has a natural Bayesian sibling (post-hoc
  Bayes-factor "power" equally condemned) — pair or defer per the ruling. Record a
  per-check disposition table before implementation.
- **Anti-two-stage invariant:** every new routing key reads DECLARED estimand/
  properties only (linear vs monotone as declared question; never
  inspect-data-then-pick). `test_no_shapiro_autoswitch`-style coverage extends to
  every new category.
- **D-05 friction rows:** dCor and some Krippendorff configurations ship
  catalog-only with falsifiable D-13 entry conditions until a published numeric
  reference value is adopted as the fixture.
- **Effect-size bands:** Landis & Koch (1977) and Koo & Li (2016) bands ship
  labeled as *conventions*, not thresholds; wired into `templates/APA-TABLE-research.md`,
  never into a blocking gate.

### 2.4 D-05 read burden

~15–20 mandatory human reads (one per new gate code + effect-size band sources).
Citation granularity ruling: **human read per CODE; bibliographic citation per
catalog ENTRY** — otherwise the burden silently triples to 90+.
Evidence packs are filed EARLY at S0 (HQ pattern proven by v2.2's HQ-8) so the
operator reads asynchronously while Phase 17 builds.

## 3. v2.4 Visual Excellence — content plan (queued)

### 3.1 Catalog spine (~80 entries, acceptance band 75–90)

Merged from five citable taxonomies: **FT Visual Vocabulary** (FT Visual
Journalism, 2016, MIT-licensed repo — the spine, ~60 unique types / 9 functions),
**Wilke** Fundamentals ch. 5 directory (~45 types, CC BY-NC-ND — the REQUIRED
uncertainty family source), **Graphic Continuum** (Schwabish & Ribecca 2014 — the
~90-type completeness benchmark), **Data Visualisation Catalogue** (Ribecca,
stable per-chart URLs for per-entry citations), **Datawrapper** (Muth 2025,
cardinality bands). Union ~110–130 names → ~95 after synonym merge → ~80 after
principled exclusions.

**Three axes per entry:** (1) FUNCTION — FT's nine + a tenth, **UNCERTAINTY**
(Wilke ch. 16: fan chart, quantile dot plot, half-eye, gradient CI band — naturally
D-12a-symmetric, covering frequentist CIs and Bayesian posteriors alike);
(2) DATA SIGNATURE — Munzner ch. 2 attribute types + cardinality bands
(machine-checkable against FIGURE-MANIFEST declarations — D-01/D-02 clean);
(3) PERCEPTUAL RANK — dominant Cleveland & McGill (1984 JASA 79:531-554) channel,
with Heer & Bostock (2010 CHI) replication as the paired citation.

**Exclusions are first-class refusal entries**, not absences (else the
"exhaustive" claim breaks against the Graphic Continuum benchmark): 3D (Munzner
ch. 6 "no unjustified 3D"; C&M volume-last), gauges (Few 2006/2013), word clouds
(Harris 2011), dual-axis (Muth 2018; existing DSX-VIZ-030), chartjunk one-offs
(Tufte 1983). Each cross-references its banning code.

### 3.2 Selection heuristic (5 layers, route-and-cite — no parallel taxonomy)

L1 question→task (Munzner ch. 3; Abela 2008 pattern-origin credit) → L2 function
category (FT flow; Few's Graph Selection Matrix corroboration) → L3 data-signature
filter (Munzner ch. 2 + Datawrapper cardinality bands) → L4 catalog shortlist
(stable entry codes; analyst declares the chosen code in FIGURE-MANIFEST) → L5
perceptual tie-break (C&M ranking + H&B replication). Ships as edits to
`references/question-taxonomy.md` / `chart-selection.md` + skill pointers.

### 3.3 Style & snippet layer (license-audited)

- `styles/*.mplstyle`: **dsx-538** forked verbatim (matplotlib BSD — safe);
  **dsx-urban** from Urban Institute's Apache-2.0 guide (Lato font = OFL,
  vendorable — this is the default house style); **dsx-econ** and **dsx-bbc**
  REIMPLEMENTED from published doctrine only (Economist 2017 styleguide PDF is
  unlicensed — cite never embed; bbplot is GPL-2 — re-derive `finalise_figure`
  behavior from the cookbook's prose, never port code). Per-file license/
  attribution headers; license audit is an explicit plan-review item.
- `templates/dsx_plotstyle.py` (~150 lines, analyst-side, matplotlib-only):
  `finalise_figure()` (title-as-takeaway, subtitle, mandatory source line),
  `direct_label()`, `save_deterministic()`.
- **Determinism recipe** (svg_sha256 seals must survive re-render): vendored OFL
  font registered via font_manager (Windows font fallback is the #1 hash-breaker),
  `svg.fonttype: path`, `svg.hashsalt`, metadata Date=None, pinned matplotlib
  version recorded in the manifest — proven by a double-render hash-equality test
  kept OFF the gate path (skipIf matplotlib absent).
- Snippet catalog per chart type routes to finding codes, never restates
  thresholds. WCAG AA contrast palettes from Urban's Apache-2.0 hexes.
- Design doctrine (12 items, each with a published source): direct labeling over
  legends, title-as-takeaway, annotation-carries-the-story, gridline minimalism,
  zero baseline, mandatory source line, small multiples over spaghetti,
  one-emphasis-color discipline, relationship-first chart choice, one-chart-one-
  message (Leo 2019 "Mistakes, we've drawn a few"), fixed canvas/aspect
  discipline, finalisation-as-function.
- **Faceting** enters as an orthogonal `facet_by` declaration (not a chart type).

### 3.4 Capstone

**Portfolio exemplar** (terminal phase): one end-to-end showcase — question →
ANALYSIS-SPEC → tests chosen via the v2.3 catalog → figures via the style layer →
sealed FIGURE-MANIFEST → What/So What/Now What narrative → REPRO-REPORT — passing
every gate at ship threshold. This is the artifact a hiring-grade senior DS reads
whole, and it doubles as the integration verification of both milestones.
