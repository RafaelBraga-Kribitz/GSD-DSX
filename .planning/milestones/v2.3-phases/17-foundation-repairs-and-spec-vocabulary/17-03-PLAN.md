<assumption_delta_decision>
Noun now primary: the estimand-KIND identity (the association/agreement/trend form a test routes on), as distinct from the pre-existing estimand-TYPE (the causal quantity admissibility adjudicates).
Decision: add-alongside. D-01 adds a 6th member, nominal_association, to the requirement's stated minimum five, and keeps the field name estimand_kind unchanged. This sits inside REQ-P17-02's own "covering at least" grant, so it is additive, not a scope escalation or a rename.
Rationale: the Statistician's carve is load-bearing — Cramér's V / phi on an unordered r-by-c table is an UNSIGNED departure-from-independence measure with no slope and no direction, so folding it into linear_association (a signed, slope-like Pearson quantity) would mis-carve the estimand space and let the Phase-18 correlation scale/kind gate wave a nominal-by-nominal "correlation" through. The orchestrator kept the name estimand_kind (rejecting relationship_kind) and answered the mis-slot concern structurally: estimand_kind and validity_frame.estimand.type live on different blocks, are read at different sites, and both carry closed-vocab membership guards with disjoint member sets, so a swapped value fails membership loudly rather than silently. This block reflects that already-settled D-01 decision; it does not re-litigate it.
</assumption_delta_decision>
