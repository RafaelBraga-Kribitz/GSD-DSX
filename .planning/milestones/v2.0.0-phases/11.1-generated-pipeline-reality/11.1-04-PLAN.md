<objective>
Make the prediction-time definition check run whenever a model is declared at all, and make an
undeclared class balance under an imbalance-unsafe metric a finding rather than a silence.

Purpose: both are silences the generated-pipeline case walks straight through. A specification that
never got as far as listing features currently skips the prediction-time check entirely, because
that check is the last statement in a function that returns early when features are blank. And an
undeclared positive rate under a metric known to be optimistic on rare positives currently produces
no finding at all — not even an acknowledgement.

Output: one check extracted to its own call site with its code number unchanged, one new branch in
the metric-choice check with a new code, tests, a decision record, and a current catalogue.
</objective>
