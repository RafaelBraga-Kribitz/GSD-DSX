**Comment/skip discipline inside line-scan helpers** (lines 167-195) — every new helper must
preserve this skip logic (comments and import lines never match):
```python
def _first_line_matching(lines: list[str], markers: tuple[str, ...]) -> int | None:
    for index, line in enumerate(lines):
        stripped = line.strip()
        if stripped.startswith("#"):
            continue
        if re.match(r"^(from|import)\b", stripped):
            continue
        for marker in markers:
            if marker in line:
                return index
    return None
```

**Error handling pattern** (lines 47-60, 142-164) — degrade-to-empty-report, never raise:

V7 in RESEARCH.md; use `match.group(1) if match else None`-style guards, never bare `.group(1)`).
