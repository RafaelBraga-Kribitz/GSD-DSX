<objective>
Close gap G-07-4: the unit-triad citation contradicts its own honesty disclosure, and the two
files carrying that citation disagree about what was confirmed.

Purpose: the phase's own research confirmed Kish (1965) section 8.2, page 258 for the
design-effect definition. What it never confirmed was a section number for the design-effect
formula itself. The disclosure that shipped says something broader and wrong — that pages were
the only locators confirmed — sitting one sentence away from the section number it denies.
dsx/mathx.py resolved the same tension by dropping the section number entirely, so the package
now states two different things about the same source. A reader cannot tell which is true, and
this is the exact class of failure the whole phase exists to prevent.

Output: three citation sites in the dsx package carrying one identical Kish locator set and one
narrowed disclosure, the citation ledger in brief.md brought into line with them, and a test
class that fails against the tree as it stands today and would fail again on any future
recurrence, including in a file that does not exist yet.
</objective>
