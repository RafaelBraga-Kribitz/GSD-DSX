<objective>
Close the reverse direction of the import boundary before the phase creates the first real
incentive to cross it, and add the frequentist-scoping predicate the adjudicator will be handed.

Purpose: `tests/test_frame_boundary.py` scans only `dsx/frame/`, so nothing today stops
`dsx/checks/stats.py` from importing `dsx.frame.admissibility`. That import would ship green while
destroying the extraction property the boundary exists to protect. Separately, the frequentist-only
scoping decision has to be made outside the adjudicator, because the adjudicator's own source is
forbidden from naming the declared paradigm at all.

Output: a second, mirror-image scanner in `tests/test_frame_boundary.py`, and
`applies_to_frequentist_admissibility` exported from `dsx/frame/paradigm.py`.
</objective>
