<objective>
Close the SC5 gap in the notebook branch of `_read_source` so that every JSON
(JavaScript Object Notation) document shape which reaches it either scans, or
returns None and is named as NOT scanned -- and none of them ends the process
with an uncaught Python exception.

Purpose: a raw uncaught exception produces Python's default exit code 1, the
same number the gate uses to mean "this file was scanned and blocked". A
continuous-integration system reading only the exit code gets the right answer
for the wrong reason, and one configured to continue on error gets no answer at
all. That is the exact contract violation this phase was chartered to close,
and it is still open for four shapes. (A fifth, originally believed open -- a
`.ipynb` file with non-UTF-8 bytes -- was found, by a pre-execution security
audit, to already exit 2 with a clear message via a different path than
`_read_source`. See the CORRECTION truth in `must_haves.truths`. It is
deliberately excluded from this plan's scope, not silently dropped.)

Output: three inline guards in the `.ipynb` branch of `_read_source`, a widened
"could not be read" reason text in `check()`, and five regression tests that pin
every remaining shape -- including one crash shape (deeply nested JSON) that
neither the verification report nor the code review found.
</objective>
