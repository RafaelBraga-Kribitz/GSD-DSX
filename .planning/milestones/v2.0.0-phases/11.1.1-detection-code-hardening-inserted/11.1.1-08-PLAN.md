<objective>
Close WR-02 in code by implementing Option B -- the decision made by the human
in the UAT test 1 resolution. A declared entrypoint that resolves but cannot be
scanned, or is declared but resolves to no file at all, currently makes
`check()` return before either `record_decision` call runs, so `DECISIONS.jsonl`
gets no entry for the judgment that was genuinely made ("this entrypoint could
not be scanned") and `dsx explain` can replay nothing for it. This plan adds the
missing `scan_path:not-scanned:<reason>` decision record on those two
early-return paths.

Purpose: the AST-DESIGN blocker table (B4/B6) specified exactly this decision
input for the declared-but-unscannable path; plans 03 through 07 each carried it
forward WITHOUT implementing it, and plans 06/07 explicitly prohibited touching
it so it could be settled deliberately rather than by default. The human settled
it: Option B, close it in code -- the decision record only, so `dsx explain` can
replay the judgment. Option C (changing the default `--verbose` render
visibility) was explicitly NOT selected and is out of scope.

Output: two inline `record_decision` calls in the `path is None` and
`source is None` early returns of `check()`, and four test changes -- the
existing "no decision record" pin rewritten to assert a record now exists, a new
pin for the path-not-found path, a new pin proving the record replays through
`collect_from_report` (the real `dsx explain` wiring), and a control proving the
default non-verbose render is byte-unchanged so Option C stays unimplemented.
</objective>
