# Phase 11.2 Plan 02: Tiered Causal-Verb Lexicon Widening Summary

**Two-tier CAUSAL_VERBS restructure (always-hit finite-verbs-and-gerunds set plus a
purpose-gated bare-infinitive/noun-homograph set) behind a single shared
`causal_verb_matches` matcher, closing the "offer bundled incentives to reduce churn" evasion
without false-positiving on "sales increase in Q4".**

## Accomplishments
- `CAUSAL_VERBS` restructured into `CAUSAL_VERBS_ALWAYS_HIT` (finite verbs unchanged, plus
  gerunds `reducing`/`increasing`/`decreasing`/`improving`/`boosting`/`lifting`/`generating`)
  and `CAUSAL_VERBS_PURPOSE_GATED` (`reduce`/`increase`/`decrease`), with `CAUSAL_VERBS` kept as
  a backward-compatible alias to the always-hit tier.
- New `causal_verb_matches(lowered) -> list[str]` in `dsx/spec.py`: always-hit members fire on
  any `\b`-bounded occurrence; purpose-gated members fire only inside a bounded
  purpose/recommendation-marker window (`to`, `in order to`, `so as to`, `aimed at`,
  `designed to`, followed by up to 30 characters, then the verb).
- Purpose-context regex uses one flat, bounded `{0,30}` quantifier per verb — no nested
  quantifier groups, no `.*` chains — mirroring `_FALSIFIER_NUMBER_RE`'s house style
  (threat T-11.2-02 mitigation).
- Umbrella provenance header above the lexicon: a `Structural criterion:` anchor to Hernán 2018
  "The C-Word" (Am. J. Public Health 108(5):616-619, DOI 10.2105/AJPH.2018.304337) carrying the
  project's unverified-locator flag pending HQ-3, plus a `vocabulary_is_not_exhaustive: true`
  editorial-closure note mirroring 11-CONTEXT D-10.
- `dsx/checks/claims.py::_check_causal_language` and
  `dsx/checks/coherence.py::_check_decision_language` both now call
  `causal_verb_matches(lowered)` instead of the previously divergent
  `[verb for verb in CAUSAL_VERBS if verb in lowered]` scan — single shared matcher, no drift.
- `tests/test_causal_verb_tiers.py` added with 7 tests covering both Tier-1 cases, gerund+hedge,
  gerund-no-hedge, the negative noun case, and both live D-06 exemption fixtures.

## Decisions Made
- **CAUSAL_VERBS alias scope:** kept the flat `CAUSAL_VERBS` name as an alias for the always-hit
  tier only, never a union with the purpose-gated tier, so a hypothetical naive future consumer
  cannot reintroduce the noun-homograph false positive.
- **Gerund coverage beyond the two named exemplars:** added gerunds for every existing finite
  verb that has one (`improving`, `boosting`, `lifting`, `generating`) in addition to the two
  plan-named (`reducing`, `increasing`) plus `decreasing`, per the plan's "and any gerund of an
  existing finite verb" grant — these are unambiguously verbal and carry no noun-homograph risk.
- **Purpose-gated tier membership held to exactly the plan's literal three members**
  (`reduce`/`increase`/`decrease`) rather than widening further, per the plan's explicit Task 2
  action text and to stay within the D-06 negative-fixture-bounded discretion.

recorded here for traceability against the plan's acceptance-criteria wording only.
