### 4. `revisit_when_is_discriminating` sibling predicate (D-07, RESEARCH landmine b)

**Analog:** `falsifier_is_discriminating` + `is_placeholder_or_refusal`
(`spec.py:476-501`) — the exact predicate shape and docstring convention to mirror,
and the function this new predicate wraps (NOT extends):

```python
# spec.py:476-488
def is_placeholder_or_refusal(value: Any) -> bool:
    """True when ``value`` is blank, an angle-bracket placeholder, or a refusal token.
    ...
    """
    if is_blank(value):
        return True
    if isinstance(value, str) and _PLACEHOLDER_RE.match(value.strip()):
        return True
    return normalize(value) in _FALSIFIER_REFUSALS


# spec.py:491-501
def falsifier_is_discriminating(value: Any) -> bool:
    """True when ``value`` names a concrete, checkable observation that would prove an
    estimand wrong — carries a comparison predicate (`FALSIFIER_DISCRIMINATORS`) or a
    numeric threshold, and is neither blank, a placeholder, nor a refusal token.
    """
    if is_placeholder_or_refusal(value):
        return False
    text = str(value).lower()
    if any(token in text for token in FALSIFIER_DISCRIMINATORS):
        return True
    return bool(_FALSIFIER_NUMBER_RE.search(str(value)))
```

New sibling — module-level function in `spec.py`, calling `falsifier_is_discriminating`
unchanged and conjoining a new window-token clause, per RESEARCH's explicit guard:

```python
def revisit_when_is_discriminating(value: Any) -> bool:
    """True when ``value`` both names a discriminating condition (reuses
    ``falsifier_is_discriminating``'s core comparison/numeric test) AND carries a
    time anchor — a duration, date/deadline, or time-anchored recurring event.
    A NEW sibling, not an extension of ``falsifier_is_discriminating`` itself:
    its two estimand callers (val.py:236, val.py:637) validate a logical falsifier
    with no time anchor, and the `good` fixture's estimand falsifier (good:303) has
    none — extending the shared predicate would regress DSX-VAL-011 on that fixture.
    """
    return falsifier_is_discriminating(value) and _has_window_token(str(value))
```

Do not touch `falsifier_is_discriminating`'s body/signature or `FALSIFIER_DISCRIMINATORS`.
`_has_window_token` should use a bounded, non-nested-quantifier regex mirroring
`_FALSIFIER_NUMBER_RE` (`spec.py:473`).

```python
def _render_decision_trail(records: "list[dict]") -> str:
    """Human-readable text: the invocation header line, then one block per
    decision record. ..."""
    if not records:
        return "no decision trail was found."

    lines: "list[str]" = []
    header = next((r for r in records if r.get("record_type") == "invocation"), None)
    if header:
        lines.append(
            f"invocation {header.get('invocation_id')} "
            f"(gate={header.get('gate_point')}, dsx={header.get('dsx_version')}, "
            f"frame_digest={header.get('frame_digest')})"
        )

    for record in records:
        if record.get("record_type") != "decision":
            continue
        lines.append("")
        lines.append(f"{record.get('id')} [{record.get('layer')}] {record.get('choice')}")
        if record.get("rule"):
            lines.append(f"  rule:           {record['rule']}")
        if record.get("citation"):
            lines.append(f"  citation:       {record['citation']}")
        if record.get("counterfactual"):
            lines.append(f"  counterfactual: {record['counterfactual']}")
```

Append a new labelled block AFTER this loop (function continues past line 649), using
the same `lines.append(...)` accumulation idiom, then a separately-labelled section
header string like `"self-reported (taken on trust, not verified by dsx)"` followed by
`spec.*` field reads passed in from the caller — `cmd_explain` already loads the spec
via `find_spec`/its own `try/except` (`cli.py:583-618`), so the new section's data comes
from that same load, not from `records`. `frame_digest` must stay only in the header
line above (`:635`) — never duplicated into the new self-reported block.

### Bounded-regex discipline (threat T-7-03)
**Source:** `dsx/spec.py:466-473`, `_FALSIFIER_NUMBER_RE = re.compile(r"\d+(?:\.\d+)?\s*(?:%|pp)?")`
**Apply to:** any new regex in the causal-verb tier-2 gate or the `revisit_when` window-token matcher — non-nested quantifiers only, no `.*` chains.

### Tolerant, degrade-not-raise trail reading
**Source:** `dsx/decisions.py::read_all` (`:128-161`) — missing file -> `[]`; undecodable bytes -> `errors="replace"`; unparseable line -> skipped, not fatal.
**Apply to:** the new amendment-counter reader in `prereg.py` — reuse `read_all`/`decisions_path` directly rather than re-implementing trail parsing.

### Dataclass `to_dict()` hardcoded `record_type`
**Source:** `DecisionRecord.to_dict()` / `InvocationHeader.to_dict()` (`decisions.py:85-88,105-108`)
**Apply to:** the new `AmendmentRecord.to_dict()` — hardcode `out["record_type"] = "amendment"`, do not consult `RECORD_TYPES`.
