## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| operator-authored ANALYSIS-SPEC → gate | Operator declares a claim type; the gate must recognise `prescriptive` and hold it to the ceiling, not skip it as an unknown type. | untrusted operator spec (YAML) |
| operator claim/decision text → causal-verb scan | Free operator prose crosses into a substring/regex scan that must catch euphemistic action forms without false-positiving on nouns and without adversarial backtracking. | untrusted free text |
| operator-declared spec identity → gate | Operator declares `spec_id` + amendment reasons; the gate trusts the declaration's FORM but cannot verify its truth. | untrusted operator declaration |
| local DECISIONS.jsonl → amendment counter | A plain, unsigned, tolerant-read local file the gate both writes and reads; anyone with file access can reset or edit it. | local unsigned trail file |
| template documentation → operator belief | A scaffold field that looks enforced but is not is a repudiation-shaped hazard (operator relies on an unchecked value). | documentation → belief |
| operator claim type + identification → gate | Operator can relabel a claim's type; the gate must not let relabelling causal→prescriptive buy a softer severity. | untrusted operator declaration |
| operator revisit_when text → window matcher | Free operator text crosses into a regex window matcher that must not expose the gate to backtracking. | untrusted free text |
| shared falsifier predicate → two consumers | `falsifier_is_discriminating` is reused; mutating it would silently regress a different family. | internal shared code |
| declared spec inputs → rendered explanation | `dsx explain` compares many declared inputs it never computes; it must disclose that boundary without mislabelling a computed value (`frame_digest`) as declared. | declared vs computed |
| corpus expectation maps → measured reality | The catch-attribution/incidental maps encode expected behaviour; a maintainer could absorb a verdict change by editing them instead of the code. | test-fixture expectation maps |
