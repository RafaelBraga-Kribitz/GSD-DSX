<objective>
Make the two shipped, operator-facing artifacts attribute the `1/(K+1)` bound the way every other
artifact in this phase already does.

Purpose: `dsx/frame/paradigm.py`'s own docstring and `references/paradigm-symmetry.md` both state
that Deng, Lu & Chen (2016) Theorem 1 licenses the prior-averaged bound under optional stopping but
does not itself state the number — the bound is unnumbered prose, given in its operational form at
the paper's Section 3.2 — and both warn in as many words that citing Theorem 1 alone for the number
would be a locator error. Two shipped artifacts commit exactly that error anyway: the `detail=` text
`DSX-PAR-011` emits at gate time, confirmed by running the real gate on 2026-08-13, and the known-bad
Bayesian fixture's own Formulation note comment.

This matters because Success Criterion 3's stated intent is that a mismatch reads as a formulation
question in five minutes, not an implementation bug for a day. A plausible-but-wrong locator in the
text an operator reads when the gate blocks is worse than no locator, because it reads as
authoritative and sends the reader to the wrong paragraph of the paper.

The paired POSTMORTEM.md already gets it right. Its wording is the target, so this is a
transcription, not a re-derivation.

Output: one corrected finding string, one corrected fixture comment, and three tests that keep both
corrected.
</objective>
