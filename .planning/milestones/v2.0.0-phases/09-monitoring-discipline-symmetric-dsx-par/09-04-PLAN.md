<objective>
Make the corpus tell the truth again, and put a test underneath the symmetry audit.

Purpose: both monitoring fixtures currently state, in their spec headers and in the Bayesian
post-mortem, that nothing in this repository adjudicates their defect today. Plan 09-03 made that
false. A known-bad corpus whose documentation contradicts the tool's behaviour is worse than no
corpus, because it is the artifact a reader trusts to tell them what the gate does and does not
catch.

Second purpose: the symmetry audit written in plan 09-01 has, until now, nothing enforcing it. Prose
asserting that neither half is cheaper to satisfy dishonestly, with nothing underneath it, is exactly
what brief D-12 fails to survive. This plan pairs it with a positive-content test that reads the
audit and compares it against the code's real clearing conditions.

This plan runs in parallel with plan 09-05. It touches no file that plan touches, and the
`DSX-PAR-002` code that plan ships does not fire on any fixture in this corpus — both monitoring
fixtures declare a `paradigm_justification`, as do the good and bad canonical fixtures.

Output: four corrected corpus files and one positive-content test.
</objective>
