<objective>
Ship the committed proof that the block is on branch identity and never on procedure merit.

Purpose: REQ-P10-04 cannot be proved by a second finding code, because knowing a substitute is more
conservative would require ranking procedures — which brief D-02 bars from the gate path and which is
Phase 11's job. It is therefore a property of the trigger, provable only by a fixture whose
substitution is strictly more conservative and which blocks anyway.

Output: one new known-bad fixture pair, its two corpus map entries, and the dedicated verify-and-ship
test the generic corpus test cannot supply.
</objective>
