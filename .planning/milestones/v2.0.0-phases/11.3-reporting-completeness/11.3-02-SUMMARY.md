# Phase 11.3 Plan 02: Unrecognised effect_size_kind Guard (DSX-STA-012) Summary

**DSX-STA-012 MEDIUM turns a silent effect-size skip into a visible finding, fired from a membership guard that precedes interpret_effect and reads a single-sourced EFFECT_SIZE_KINDS frozenset shared with mathx.py.**

## Performance

- **Duration:** ~12 min
- **Completed:** 2026-08-27
- **Tasks:** 2 (RED, GREEN)
- **Files modified:** 4 (1 created, 3 modified)

## Accomplishments
- Minted DSX-STA-012 (MEDIUM): an effect_size_kind outside the recognised {d, h, r} set is now a visible finding instead of silently disabling the DSX-STA-011 magnitude guard.
- Single-sourced the recognised set: `EFFECT_SIZE_KINDS = frozenset({"d", "h", "r"})` hoisted to `dsx/mathx.py` module level; `interpret_effect` derives its recognised set from it; `dsx/checks/stats.py` imports it so the guard and the dispatch cannot drift.
- Guard PRECEDES `interpret_effect` and routes the kind through `normalize()` first, so mathx's `ValueError`-on-unknown-kind never reaches the gate path and a crafted mixed-case/whitespace value cannot slip past.
- New disjoint test module `tests/test_effect_size_kind.py` (4 cases); catalogue regenerated 249 -> 250 codes.

## Decisions Made
- Chose D-11 option (a) single-sourcing (one hoisted frozenset the callee derives from) over the equality-assertion alternative, eliminating the drift surface entirely rather than testing for it.
- DSX-STA-012 was NOT added to the `_D05_ALLOWLIST_*` sets in `scripts/gen-finding-catalogue.py`: DSX-STA-* is a pre-existing family and that script is outside this plan's `files_modified` set. The `Structural criterion:` docstring line is carried per the plan, but no Citation line or `# D-05:` test marker is required for the gate because the code is not on the D-05 allow-list. The catalogue `--check` gate passes at exit 0.
