<objective>
Close the Phase 6 verification BLOCKER: make the decision trail a side channel that no on-disk
state can turn into a gate verdict, and make `dsx explain`'s "always returns 0" contract
unconditional rather than an enumeration (REQ-P6-07, REQ-P6-08, D-17, D-19; brief §4 D-04).

Purpose: `06-VERIFICATION.md` falsified 06-09's own must-have — "a failure to write
`DECISIONS.jsonl` never changes a gate's exit code" — by reproducing, against the live CLI, that a
single non-UTF-8 byte in the trail file makes `dsx explain --phase-dir <dir>` exit 2 and makes
`dsx gate plan --spec examples/good-ANALYSIS-SPEC.yaml` exit 2 on a spec that otherwise passes
cleanly. The root cause is `read_all()`'s unguarded `read_text(encoding="utf-8")`; the reachability
is `cmd_explain`'s complete absence of a guard and `_write_decision_trail`'s guard being narrower
than the invariant its own docstring states.

Output: an encoding-tolerant and unreadable-path-tolerant `read_all()`, guards at both call sites
stated in terms of `Exception` rather than one exception class, a documented concurrency limitation
for the non-atomic invocation-id allocation, and the committed regression tests that make the
falsified invariant provable rather than asserted.
</objective>
