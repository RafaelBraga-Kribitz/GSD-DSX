# Bundle recommender readout

**Audience:** VP Merchandising
**Decision:** roll out the bundle recommender if the order-value uplift clears the $0.50 floor.

## Headline

The bundle recommender raises average order value by $1.85
(95% CI $0.92 to $2.78) per completed order in the test window.

The interval clears the pre-declared $0.50 practical floor, so the decision rule
recommends rollout. No guardrail degraded over the two-week window.

## Limitations

This estimates the effect on order value only and says nothing about order
frequency. It was measured over two weeks; seasonal baskets may differ.
