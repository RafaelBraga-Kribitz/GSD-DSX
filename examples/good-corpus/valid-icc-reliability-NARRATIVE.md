# ICC-reliability readout (clean negative control)

**Audience:** VP Merchandising
**Status:** calibration control — a correctly-declared ICC that the gate should
pass silently.

## Headline

The bundle recommender raises average order value by $1.85
(95% CI $0.92 to $2.78) per completed order in the test window.

The numbers above are illustrative and pinned. This spec exists as a clean
negative control: it declares an ICC with a complete, in-vocabulary
(model, type, definition) triple, so the ICC-completeness gate reaches its branch
and stays silent.

## Limitations

A calibration control. It carries no decision weight and reports no real finding
about any product.
