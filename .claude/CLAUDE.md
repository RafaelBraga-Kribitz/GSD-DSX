# Project context for every agent

Write in plain sentences. Expand every acronym on first use in each response. No
invented abbreviations. Before any detail, summarise what changed and why in five
lines or fewer. When a choice is needed, follow `skills/decision-format/SKILL.md`
exactly, including the default-if-no-answer line. State what choice you made and
why, for both deterministic and stochastic steps. Ask what the real question is
when the request is ambiguous, and challenge my framing when you think it is
wrong.
